# Number Guessing Game

A simple Python CLI game where the computer picks a number 1-10 and you have to guess it.

## How to Play
1. Run `python number_guessing_game.py`
2. Enter your guess
3. Get hints - Too High / Too Low
4. Win in minimum tries!

## Features
- Random number generation
- Input validation
- Try counter

## Tech Used
Python 3, random module
